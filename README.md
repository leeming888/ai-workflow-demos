| 档位 | 交付 | 价格 | 周期 |
|---|---|---|---|
| **轻量 · 单一场景** | 一个场景跑通 + 操作视频 + 3 天答疑 | **1,500 起** | 3–5 天 |
| **标准 · 中等复杂度** | 多场景串联 + 私有化部署可选 + 15 天陪跑 | **5,000–15,000** | 7–14 天 |
| **企业级** | 定制架构 + 内网部署 + 团队培训 + 月度维护 | **另议** | 按需 |
| **月度维护** | 巡检 + 调优 + 新需求迭代 | **800–3,000/月** | — |

**定价三原则**：
1. **第一次报价永远不是最低价** —— 报标准价，让客户有砍价的余地，你也有降价空间
2. **报价必须写清"包含什么"** —— 场景数、部署方式、陪跑天数、改几次，避免后期扯皮
3. **低于时薪的单不接** —— 低价单接多了，账号会被钉死在低价池

## 6. 三个我能提前说清楚的坑（省你时间）

**① 别一上来做大而全**
先跑通**一个**场景，让老板看到效果。上来做全套 → 三个月后客户还没看到东西 → 尾款收不到。

**② 别把 AI 生成的东西原封不动交付**
系统跑起来了，但结果没人用 = 白做。**最后一步"人工复核"的流程要一起设计。**

**③ 需求边界不写清 = 无限改**
开工前必须书面确认：输入是什么、输出是什么、异常怎么处理。**"改到满意为止"这种话不能答应。**

## 7. 合规声明

只做**公开数据采集与合规的业务自动化**。
- 不做绕过平台风控、绕过反爬、绕过审核的自动化
- 不做灰产、刷量、账号批量养号
- 涉及数据采集的，只做公开可访问的数据
- 客户数据不出内网（支持私有化部署）

**这个声明不是装饰。** 它决定了你能不能长期做，也决定了客户敢不敢把钱和业务交给你。
