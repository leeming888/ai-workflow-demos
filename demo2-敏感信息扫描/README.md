# Demo 2 · 敏感信息扫描闸门（可运行）

> **解决什么问题**：AI 自动化会把内容往云端推（资料库 / 网盘 / Git / 第三方 API）。一旦把 API Key、账号、凭证写进 prompt 或文档，**就永久留在云端了，撤不干净**。
>
> 尤其可怕的是：多个自动化 prompt 里都写了「不入金：API Key / 账号 / 凭证」，**但那是靠模型自觉**。

---

## 核心观点（明哥原话）

> **"这是纯正则脚本，比在 8 个 prompt 里写十遍『不许写』可靠。"**

**靠自觉的规则 = 会漏的规则。只有代码才是硬闸门。**

---

## 能力

| 项 | 说明 |
|---|---|
| 扫描对象 | 单个文件 / 整个目录 |
| 识别类型 | API Key、Token、密码、账号、身份证、银行卡、私钥等 |
| 输出 | 命中位置 + 类型 + 脱敏片段 |
| 退出码 | `0` 干净 / `1` 发现敏感 / `2` 参数错 |

**关键设计：可挂进自动化做前置闸门**
```bash
python scan_sensitive.py --strict <file>    # 发现敏感直接 exit 1 → 自动化流程中断
```

→ **云端自动化在上传前自动跑这一关，命中就不上传。**

---

## 运行方式

```bash
python scan_sensitive.py <file.md>              # 扫描单个文件
python scan_sensitive.py --dir <目录>            # 扫描整个目录
python scan_sensitive.py --strict <file>         # 发现敏感就 exit 1（给自动化用）
```
