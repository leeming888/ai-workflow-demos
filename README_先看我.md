## 三条纪律（贴在电脑旁）

**① 别一上来做大而全**
先跑通**一个**场景。上面做完大而全的方案，三个月后客户还没看到东西 → 尾款收不到。

**② 报价第一次永远不是最低价**
报 5,000，落到 1,500-3,000 是常态。
报 1,500 就只能接 1,500 的活。

**③ 低于时薪不接**
低价单接多了，账号被钉死在低价池，以后想涨价没人信。
