# 「面试官最可能追问的问题清单」

以下问题均尽量要求候选人提供**具体平台、账号、日期、数据、作品或决策过程**，避免只回答“参与过、协助过、提升了”。

---

## 1. 数据真实性追问

1. **你在A公司具体负责哪些店铺、多少个SKU？**请说出所在平台、店铺品类、你负责的账号名称或后台截图，并说明每月处理的订单量、异常订单量分别是多少；简历中提到的“618、双11”具体是哪一年、活动GMV和转化率分别是多少？  
2. **你在B公司运营的账号是哪个平台、什么垂类？**请提供账号链接或可验证的作品链接，并说明账号粉丝量、月均发布量、近30条视频的平均播放量、互动率和涨粉数；如果不能公开公司账号，请说明哪些数据可以脱敏后展示。  
3. **简历中提到的“爆款视频”到底有多爆？**请给出视频链接或明确的作品标识、上线日期、播放量、点赞量、评论量、转发量、涨粉数，并说明播放数据是发布后多久统计的、由哪个后台或工具导出。  
4. **你制作的数据日报和视频复盘具体长什么样？**请现场展示一份脱敏后的日报、周报或复盘表，说明用了哪些指标、数据来源、统计周期，以及其中一项你发现的异常和最终处理结果。

---

## 2. 业务决策追问

1. **在电商运营中，你真正独立做过哪项决策？**请选择一次具体问题，按“当时看到什么数据—如何拆解原因—提出什么方案—主管如何决策—最终结果如何”的顺序复盘，并给出优化前后的转化率、客单价或退款率。  
2. **短视频复盘中，你发现过账号最明显的什么问题？**请拿近30条或近90条视频的数据说明判断依据。例如开头过长、选题重复或转化不佳，你具体修改了哪一部分，之后哪些指标发生了变化？  
3. **如果下周让你接手一个10万粉但近一个月播放量下降30%的账号，你会如何制定首周计划？**请说明先看哪些指标、如何确定问题、准备测试哪些选题或内容形式，以及用什么结果判断方案有效。  
4. **你负责的脚本或视频最终以什么标准判断“有效”？**请说明播放量、完播率、互动率、涨粉率、点击率或转化率中你最关注的两项，给出账号正常基线、优秀阈值，以及你采取低效内容止损的具体规则。

---

## 3. 能力深度追问

1. **请现场拆解一条你独立完成的视频。**从选题依据、脚本结构、前3秒设计、镜头安排、字幕和音乐、剪辑节奏，到封面标题逐项说明；请明确哪些环节由你完成，哪些由设计、拍摄或剪辑同事完成。  
2. **你在脚本策划中具体使用过什么方法？**请解释如何结合账号定位、目标用户、内容关键词和同类账号数据形成选题，并举出一个被你验证有效、后来被固定为栏目的选题类型。  
3. **你能否熟练使用剪映、Excel、Photoshop和平台后台？**请分别说明你实际做过的功能，例如剪映的关键帧与字幕处理、Excel的函数或透视表、Photoshop的图层与蒙版、平台后台的哪些数据指标；不会的功能也请如实说明。  
4. **你如何证明自己具备短视频运营能力，而不只是会发布和做基础剪辑？**请展示作品集、脚本模板、选题库、复盘表或账号运营案例，并说明其中一项方法后来如何被团队采用。

---

## 4. 动机与稳定性追问

1. **你的求职意向同时写了“运营专员”和“短视频运营”，你到底更想做什么？**请说明首选岗位、备选岗位，以及电商运营经验如何支持你转做短视频运营；如果只能选择一个岗位，你会选哪个，为什么？  
2. **你从电商运营转到短视频运营的原因是什么？**请结合具体时间节点说明转行动机，例如是否提前学习剪辑、运营个人账号或接受过培训，并说明做了哪些准备、持续投入了多久。  
3. **为什么你只做了约一年短视频运营就离开B公司？**请说明离开时的真实原因、团队存在的问题以及自己从中获得的成长，不要只回答“个人原因”或“公司变动”。  
4. **如果入职后发现日常工作中有较多数据整理、发布执行和临时活动支持，而你真正想参与的是选题和增长，你通常会如何沟通？**请说明你希望获得的职责范围、衡量方式和阶段性目标。

---

## 5. 离职原因与空窗期追问

1. **请逐段核对时间线：2022年7月入职A公司、2024年8月离职、2024年9月入职B公司、2025年8月离职，为什么当月就离职或入职？**请说明离职通知期、交接情况以及是否真正完成入职。  
2. **从2025年8月离职至今这段期间，你具体在做什么？**请按月说明求职、学习、兼职或个人账号运营情况；如果运营过个人账号，请给出账号链接、发布数量及涨粉或播放数据。  
3. **A公司和B公司分别是什么性质的合同关系？**请说明劳动合同主体、社保或公积金缴纳主体、工作地点、是否外包或派遣，以及这些情况为什么没有在简历中写清楚。  
4. **如果你上一份工作只做了不到一年，招聘方如何判断你不会再次短期离职？**请说明你对理想工作至少投入多久，以及在没有明显发展机会时通常会通过什么方式处理，而不是直接离职。

---

## 建议优先准备的“证物清单”

- A公司：店铺后台截图、日报样本、一次大促复盘、具体异常订单案例。  
- B公司：账号链接或脱敏作品、脚本原稿、剪辑工程文件、复盘表、爆款数据截图。  
- 个人经历：作品集链接、课程或学习记录、个人账号运营数据。  
- 离职与空窗期：劳动合同时间、离职证明、真实且可核验的近期状态说明。  

**核心原则：每个数字都要能说明来源、统计周期、统计口径和个人贡献；无法提供证据的数据应主动删掉，而不是模糊表述。**
